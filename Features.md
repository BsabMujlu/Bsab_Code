# Bsab Code v2.0 Alpha — Modern

**Bsab Code v2.0 Alpha has been released!**

Featuring the **Modern** version code, Bsab Code v2.0 Alpha introduces numerous new features, user interface improvements, and foundational enhancements designed to support future development.

### ✨ New Features and Improvements

* **New User Interface:** A redesigned, more modern, and user-friendly interface.
* **File Manager:** Manage code files more easily.
* **BsabShell File Creation:** Create code files for BsabShell.
* **Code Import and Export:** Import and export code files with ease.
* **Extensible Language Infrastructure:** A foundation for adding support for other programming languages in future releases.
* **Six Language Options:** Support for six languages, making Bsab Code more accessible to a wider range of users.
* **Enhanced Window Management:**

  * Snap windows to the right or left side of the screen to occupy the corresponding half.
  * Display a window-resizing panel when a window is snapped to the top edge of the screen.
  * Easily maximize, minimize, and resize windows.
  * Bring a window to the foreground simply by clicking on it, similar to Windows.
* **New Commands:** The command system has been expanded with additional commands.
* **Improved Command Organization:** Commands are now more systematically organized for a cleaner experience.
* **Font Customization:** Customize the font to suit your preferences.
* **Enhanced Theme Customization Menu:** Improvements to the menu for selecting and customizing themes.
* **Deep Console — First Announcement:** Deep Console has been officially announced for the first time as a new component of the Bsab Code ecosystem.

### 🚀 What's Next?

Bsab Code v2.0 Alpha marks a new stage in the project's development. With its expanded feature set and extensible infrastructure, this release lays the groundwork for future improvements and additional capabilities.
