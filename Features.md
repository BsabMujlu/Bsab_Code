# v2️⃣.0️⃣ Bsab Code v2.0 Alpha — Modern

## 🚀 Bsab Code v2.0 Alpha Has Been Released!

**Bsab Code v2.0 Alpha**, featuring the **Modern** version code, introduces a major set of improvements to the Bsab Code experience. This release focuses on interface modernization, file management, code import and export, window management, command organization, personalization, and the foundations for future programming language support.

Version 2.0 Alpha represents an important step in the evolution of Bsab Code, bringing together usability improvements and new capabilities while preparing the project for future development.

---

## ✨ New Features and Improvements

### 🎨 1. New User Interface

Bsab Code v2.0 Alpha introduces a redesigned user interface intended to provide a more modern, organized, and user-friendly experience.

The updated interface aims to make the application easier to navigate and interact with, creating a more accessible environment for working with code and using the available tools.

Key improvements include:

* A redesigned visual experience.
* A more modern interface structure.
* Improved presentation of application features.
* A more user-friendly environment for everyday use.

### 📁 2. File Manager

A file manager has been introduced to make working with code files more convenient.

This feature provides a dedicated way to manage code files within the Bsab Code environment, helping users organize their work and access their files more easily.

The file manager is an important addition to the application's workflow, bringing file management closer to the coding experience.

### 💻 3. BsabShell Code File Creation

Bsab Code v2.0 Alpha introduces the ability to create code files for **BsabShell**.

This feature establishes a more direct workflow for creating and working with BsabShell code files within the Bsab Code environment.

It also contributes to the development of the Bsab Code ecosystem by strengthening the relationship between the editor and BsabShell.

### 📤 4. Code Import and Export

Code import and export functionality has been added to make code files easier to transfer and manage.

**Importing code** allows users to bring existing code files into their workflow, while **exporting code** provides a way to save or transfer code files for use outside the current editing session.

These capabilities improve flexibility and make it easier to work with code files across different stages of development.

### 🧩 5. Extensible Programming Language Infrastructure

Bsab Code v2.0 Alpha introduces foundational infrastructure intended to support the addition of other programming languages in future releases.

This is an important step toward making Bsab Code more extensible and adaptable as the project grows.

The infrastructure is designed with future expansion in mind, creating a foundation on which additional language support may be developed.

**Note:** This infrastructure prepares the project for future language support; it does not necessarily mean that additional programming languages are already supported in this release.

### 🌍 6. Six-Language Interface Support

Bsab Code v2.0 Alpha includes support for **six interface languages**, allowing users to interact with the application in different languages.

Multilingual support helps make the application more accessible to a broader audience and improves the experience for users who prefer an interface in their own language.

This feature is part of the effort to make Bsab Code more adaptable to different users and usage preferences.

### 🪟 7. Enhanced Window Management

Window management has been improved to make working with application windows more convenient and intuitive.

The new behavior includes several window placement and sizing features inspired by familiar desktop window management workflows.

#### Left and Right Window Snapping

Windows can be positioned against the left or right edge of the screen to occupy the corresponding half of the display.

This makes it easier to arrange windows side by side and use the available screen space more efficiently.

#### Top-Edge Window Resizing Panel

When a window is positioned against the top edge of the screen, a window-sizing panel is displayed to provide access to window sizing options.

This helps users manage window dimensions more conveniently through the available interface.

#### Window Maximization and Minimization

Window sizing controls make it easier to maximize and minimize windows as part of everyday use.

These controls help users adjust their workspace according to their current needs.

#### Click-to-Foreground Behavior

Clicking a window brings it to the foreground, allowing users to interact with it more directly when multiple windows are present.

This behavior follows a familiar desktop interaction pattern similar to window handling in Windows.

Together, these improvements aim to create a more flexible and efficient window management experience within Bsab Code.

### ⌨️ 8. New Commands

The command system has been expanded with additional commands.

These additions extend the available command functionality and provide more options when interacting with Bsab Code.

The introduction of new commands also contributes to the ongoing development of the application's command-based workflow.

### 🗂️ 9. Improved Command Organization

The organization of commands has been improved to create a more structured and consistent command system.

A clearer command organization helps make the available functionality easier to understand and provides a better foundation for future command additions.

This improvement supports the continued expansion of Bsab Code without losing sight of usability and maintainability.

### 🔤 10. Font Customization

Bsab Code v2.0 Alpha introduces font customization, giving users greater control over the application's text appearance.

Users can personalize the font according to their preferences, helping create a more comfortable and personalized working environment.

This feature adds another layer of customization to the overall Bsab Code experience.

### 🎨 11. Enhanced Theme Customization Menu

The theme customization menu has been improved to provide a better experience when selecting and customizing the application's appearance.

The updated menu builds on Bsab Code's personalization capabilities and makes theme-related options easier to access and work with.

Combined with font customization, this improvement gives users more flexibility in shaping their preferred visual environment.

### 🔬 12. Deep Console — First Official Announcement

**Deep Console** has been announced for the first time as a new component of the Bsab Code ecosystem.

This announcement marks the introduction of Deep Console to the project's development roadmap and highlights the continued expansion of the Bsab Code ecosystem.

Further details about its functionality and availability can be documented as development progresses.
