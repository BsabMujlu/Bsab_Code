# Bsab Code... What is the Bsab Code
Bsab Code is a Turkish-friendly coding terminal developed by **Bsab Studious**, with the goal of making coding simpler, more accessible, and easier to understand. Designed with an emphasis on usability and accessibility, Bsab Code provides an approachable environment for users who want to explore coding, write code, and manage their coding projects without being overwhelmed by unnecessary complexity.

With its intuitive user interface, practical tools, customizable appearance, and beginner-friendly approach, Bsab Code aims to create a more comfortable coding experience for users with different levels of experience. Its features include code file management, code import and export, command-based functionality, font and theme customization, and support for multiple interface languages.

Bsab Code is also being developed with future expansion in mind. Its extensible language infrastructure lays the groundwork for potential support for additional programming languages, while ongoing improvements to its interface, commands, and window management aim to make the application more convenient and flexible.

Whether you are taking your first steps into coding, experimenting with code files, or exploring the tools available within the Bsab Code environment, the project aims to provide a practical starting point for your coding journey.

**Bsab Code is an evolving project.** New features, improvements, and capabilities may be introduced as development continues, with the long-term goal of building a more capable, customizable, and accessible coding environment.

## 💻 How Can I Use Bsab Code?

There are currently two ways to access Bsab Code, depending on your preference.

### 1. Run Bsab Code Locally

You can download the HTML file directly from this GitHub repository and run it locally in your web browser.

**How to get started:**

1. Open this GitHub repository.
2. Locate the HTML file for Bsab Code.
3. Download the file to your computer.
4. Open the downloaded HTML file in a compatible web browser.
5. Start using Bsab Code directly in your browser.

This method allows you to access the locally downloaded version without visiting the project website every time. Depending on the implementation, some features may require an internet connection or additional resources to function correctly.

### 2. Use Bsab Code v1.0 on Our Website

If you prefer not to download any files, you can use **Bsab Code v1.0 directly through our official project website**.

Visit the following link to access the web version:

**[Open Bsab Code Web](https://bsabstudious.wixsite.com/g-g-b/bsab-code)**

The website provides access to Bsab Code v1.0 through your browser, without requiring you to download and open the HTML source file manually.

# THE NEW CHANGES
# v2.0
**Bsab Code v2.0 Alpha has been released!**

Featuring the **Modern** version code, Bsab Code v2.0 Alpha introduces numerous new features, user interface improvements, and foundational enhancements designed to support future development.

**✨ New Features and Improvements**

* **New User Interface:** A redesigned, more modern, and user-friendly interface.
* **File Manager:** Manage code files more easily.
* **BsabShell File Creation:** Create code files for BsabShell.
* **Code Import and Export:** Import and export code files with ease.
* **Extensible Language Infrastructure:** A foundation for adding support for other programming languages in future releases.
* **Six Language Options:** Support for six languages, making Bsab Code more accessible to a wider range of users.
* **Enhanced Window Management:**

  * Snap windows to the right or left side of the screen to occupy the corresponding half.
  * Display a window-resizing panel when a window is snapped to the top edge of the screen.
  * Easily maximize, minimize, and resize windows.
  * Bring a window to the foreground simply by clicking on it, similar to Windows.
* **New Commands:** The command system has been expanded with additional commands.
* **Improved Command Organization:** Commands are now more systematically organized for a cleaner experience.
* **Font Customization:** Customize the font to suit your preferences.
* **Enhanced Theme Customization Menu:** Improvements to the menu for selecting and customizing themes.
* **Deep Console — First Announcement:** Deep Console has been officially announced for the first time as a new component of the Bsab Code ecosystem.

### 🚀 What's Next?

Bsab Code v2.0 Alpha marks a new stage in the project's development. With its expanded feature set and extensible infrastructure, this release lays the groundwork for future improvements and additional capabilities.
